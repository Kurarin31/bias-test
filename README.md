# 自担本命

四十道追星日常选择题，答完给出你和自担的关系类型与六维追星体质，附一个本命指数。

## 打开方式

- 线上：直接访问 Pages 地址
- 本地：双击 `index.html`，或 `自担本命测试.html`

## 内容

- 16 个结果类型，每种都有 slogan、为什么是你、隐藏特质
- 结果页可以存成 1080×1440 的图（严格 3:4），图里没有链接和账号
- 复制文案只有两行：关系类型 + tag 与 slogan
- 不发链接、不带平台标识，可反复重测

## 修改文案

结果类型文案在页面里的 `const DATA` 里，改 `name` / `tag` / `slogan` / `why` / `secret` 即可，`sig` 是匹配用的八维签名，改了文案不用动它。
